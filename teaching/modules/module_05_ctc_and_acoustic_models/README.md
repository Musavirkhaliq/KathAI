# Module 05: Connectionist Temporal Classification & Acoustic Modeling

## Module Description
Alignment problem, CTC blank symbol, collapse operator, forward-backward algorithm, CTC loss derivation, and PyTorch training loops.

## Primary Research Connection
Stage 4 (Character CTC Head) and Stage 8 (B-01 Training Implementation).

## Lectures in this Module

- **[LECTURE_14](../../lectures/lecture_14/README.md)**: Sequence Alignment and the Fundamental CTC Problem
- **[LECTURE_15](../../lectures/lecture_15/README.md)**: CTC Mathematics: Forward-Backward Algorithm and Loss Derivation
- **[LECTURE_16](../../lectures/lecture_16/README.md)**: Building the Kashmiri Acoustic Model (XLS-R + Char CTC)
- **[LECTURE_17](../../lectures/lecture_17/README.md)**: Anatomy of the PyTorch ASR Training Loop

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
