# Module 08: Benchmarking, Error Analysis & Statistical Evaluation

## Module Description
Levenshtein distance, WER, CER, diagnostic error atlases, benchmark freezing, paired bootstrap testing, and Wilcoxon signed-rank significance.

## Primary Research Connection
Stage 18A (Error Atlas), Stage 22B (Benchmark), and Stage 27 (Statistical Significance).

## Lectures in this Module

- **[LECTURE_24](../../lectures/lecture_24/README.md)**: Word Error Rate (WER), Character Error Rate (CER), and Levenshtein DP
- **[LECTURE_25](../../lectures/lecture_25/README.md)**: Designing Scientific Speech Benchmarks: Isolation, Integrity, and Freezing
- **[LECTURE_26](../../lectures/lecture_26/README.md)**: Statistical Significance in Speech Research: Paired Bootstrap and Wilcoxon Tests

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
