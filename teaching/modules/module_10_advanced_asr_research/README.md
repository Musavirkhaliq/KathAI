# Module 10: Advanced Research Directions & Frontier Techniques

## Module Description
N-best oracle search ceilings, CandidateRelativeRanker, negative results in reranking, conversational dialectal mismatch, and ByT5 romanization.

## Primary Research Connection
Stage 7 (ByT5), Stage 21A (Oracle ceiling), and Stage 24 (Neural reranker training).

## Lectures in this Module

- **[LECTURE_31](../../lectures/lecture_31/README.md)**: Neural Sequence Reranking: Oracle Ceilings, N-Best Lists, and Negative Limits
- **[LECTURE_32](../../lectures/lecture_32/README.md)**: Overcoming Dialectal Mismatch, Code-Switching, and Low-Resource Bottlenecks

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
