# Module 07: Decoding, Search Spaces & Language Modeling

## Module Description
Greedy search vs prefix beam search, KenLM n-gram models, Kneser-Ney smoothing, acoustic-language interaction, and temperature scaling.

## Primary Research Connection
Stage 5 (KenLM), Stage 7 (Decoders), Stage 21B (Calibration), and Stage 23 (Acoustic-LM Topology).

## Lectures in this Module

- **[LECTURE_21](../../lectures/lecture_21/README.md)**: CTC Greedy Decoding, Prefix Beam Search, and Token Collapsing
- **[LECTURE_22](../../lectures/lecture_22/README.md)**: N-Gram Language Models, Kneser-Ney Smoothing, and KenLM Integration
- **[LECTURE_23](../../lectures/lecture_23/README.md)**: Acoustic-Language Interaction, Temperature Scaling (T=1.08), and Shallow Fusion

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
