# Module 11: Production Systems & ML Research Engineering

## Module Description
Method C2 chunking, streaming inference, web UI deployment, modular package architecture (`src/`), configs, and regression test suites.

## Primary Research Connection
Stage 22C (Chunking), Stage 26 (Modular refactoring), and transcribe_kashmiri.py.

## Lectures in this Module

- **[LECTURE_33](../../lectures/lecture_33/README.md)**: Production Deployment: Method C2 Chunking, Web UI, and Latency Optimization
- **[LECTURE_34](../../lectures/lecture_34/README.md)**: Reproducible Machine Learning Research Engineering and Code Architecture

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
