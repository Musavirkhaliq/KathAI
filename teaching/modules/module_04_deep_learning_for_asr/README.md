# Module 04: Deep Learning Foundations for Speech Representation

## Module Description
Computation graphs, temporal convolutions, 7-layer CNN receptive fields, multi-head self-attention, and wav2vec 2.0 / XLS-R self-supervision.

## Primary Research Connection
Stage 4 (Tokenization), Stage 8 (B-01 XLS-R Foundation), and Stage 13 (CNN Unfreezing Negative Results).

## Lectures in this Module

- **[LECTURE_10](../../lectures/lecture_10/README.md)**: Neural Networks, Computation Graphs, and Sequence Modeling
- **[LECTURE_11](../../lectures/lecture_11/README.md)**: Temporal Convolutions and the 7-Layer Wav2Vec2 Feature Extractor
- **[LECTURE_12](../../lectures/lecture_12/README.md)**: Multi-Head Self-Attention and Transformer Architectures
- **[LECTURE_13](../../lectures/lecture_13/README.md)**: Self-Supervised Speech Representation: wav2vec 2.0 & XLS-R

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
