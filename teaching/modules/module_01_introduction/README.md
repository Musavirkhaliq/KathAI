# Module 01: Introduction to Speech Recognition & The Kashmiri Frontier

## Module Description
Fundamental concepts of automatic speech recognition, acoustic signals, pipeline architectures, and low-resource language challenges.

## Primary Research Connection
Stage 1 (Inception & Harvest) and Stage 22C Production Pipeline.

## Lectures in this Module

- **[LECTURE_01](../../lectures/lecture_01/README.md)**: What Is Automatic Speech Recognition?
- **[LECTURE_02](../../lectures/lecture_02/README.md)**: Anatomy of an End-to-End ASR Pipeline

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
