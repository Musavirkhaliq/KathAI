# Module 03: Kashmiri Linguistics, Orthography & Dataset Engineering

## Module Description
Kashmiri phonology, Perso-Arabic orthography, Unicode normalization, zero-speaker overlap partitioning, and manifest engineering.

## Primary Research Connection
Stage 2 (Orthography), Stage 3 (Splits), Stage 10 (Quran Ingestion), and Stage 22 (WAAZ Expansion).

## Lectures in this Module

- **[LECTURE_06](../../lectures/lecture_06/README.md)**: Kashmiri Linguistics, Phonology, and Perso-Arabic Orthography
- **[LECTURE_07](../../lectures/lecture_07/README.md)**: Audio Corpus Harvesting, Field Recording, and Speaker Diversity
- **[LECTURE_08](../../lectures/lecture_08/README.md)**: Research-Grade Manifest Engineering and Quality Gates
- **[LECTURE_09](../../lectures/lecture_09/README.md)**: Zero-Speaker Overlap Partitioning and Benchmark Contamination

## Key Learning Outcomes
By completing this module, students will:
1. Master the theoretical mathematics and engineering principles of this stage of the ASR pipeline.
2. Understand the exact historical decisions, failures, and empirical breakthroughs achieved in the Kashmiri AI initiative.
3. Implement, debug, and run corresponding modular code on authentic speech datasets.
