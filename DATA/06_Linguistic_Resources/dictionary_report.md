# Kashmiri Dictionaries & Lexical Resources Audit

## 1. Executive Summary

The lexical inventory contains **131,231 entries** with **29,472 unique words/headwords** compiled across historical dictionaries, academic lexicons, and pronunciation databases.

## 2. Key Lexical Assets

1. **Grierson Kashmiri-English Dictionary**: Classical comprehensive lexicon.
2. **Master Lexicon Cache (`kashmiri_lexicon_cache.json`)**: 3.7 MB normalized lexicon for CTC beam search language model constraints.
3. **UChicago S. Hassan Kashmiri Lexicon**: 1,876 spoken audio headword pronunciations.
4. **Corpus Lexicon Vocabulary (`corpus_lexicon_vocabulary.txt`)**: 4.9 MB tokenized vocabulary supporting ASR decoding.
